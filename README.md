# AI Interview Prep

An AI-powered interview preparation platform that analyzes a
job description and candidate profile to generate a personalized
interview strategy.

## Features

- User authentication
- JWT-based authentication
- Job description analysis
- Resume upload
- AI-powered interview strategy
- Personalized interview reports
- Previous interview reports

## Tech Stack

### Frontend

- React
- React Router
- SCSS
- Vite

### Backend

- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT
- Gemini API

## Environment Variables

Create a `.env` file in the backend:

```env
MONGO_URI=your_mongodb_uri
JWT_SECRET=your_jwt_secret
GEMINI_API_KEY=your_gemini_api_key
```
